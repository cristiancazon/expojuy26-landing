# ExpoJuy 2026

Landing page de ExpoJuy 2026, la feria comercial e industrial que conecta empresas, emprendedores, instituciones y visitantes del Norte Argentino con oportunidades de alcance nacional e internacional.

La experiencia presenta la información central del evento en un sitio moderno, responsivo y accesible, con una identidad visual inspirada en Jujuy y transiciones que acompañan la navegación sin distraer del contenido.

## Características

- Portada audiovisual con video de fondo y paisaje animado.
- Presentación general de ExpoJuy 2026.
- Cronograma de actividades y conferencias.
- Noticias y novedades del evento.
- Plano interactivo para explorar espacios y stands.
- Información de entradas y acreditaciones.
- Carrusel de sponsors con pausa al posicionar el cursor.
- Galería de fotos con visor ampliado y navegación por teclado.
- Formulario y canales de contacto.
- Asistente integrado en la interfaz.
- Diseño adaptado a computadoras, tablets y teléfonos.
- Respeto por la preferencia de movimiento reducido del usuario.

## Tecnologías

- [Next.js 14](https://nextjs.org/)
- [React 18](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Framer Motion](https://www.framer.com/motion/)
- [Lucide React](https://lucide.dev/)

## Requisitos

- Node.js 18.17 o una versión posterior compatible con Next.js 14.
- npm.

## Ejecución local

Instalar las dependencias:

```bash
npm install
```

Iniciar el entorno de desarrollo:

```bash
npm run dev
```

El sitio estará disponible normalmente en [http://localhost:3000](http://localhost:3000).

## Compilación para producción

```bash
npm run build
npm run start
```

## Estructura principal

```text
public/                  Recursos gráficos, video e imágenes
src/app/                 Página principal, estilos y metadatos
src/components/layout/   Navegación y pie de página
src/components/sections/ Secciones de la landing page
src/components/ui/       Componentes de interfaz y movimiento
src/lib/                 Datos y utilidades del proyecto
```
